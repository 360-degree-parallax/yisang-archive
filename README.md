# 李箱 아카이브

작가 이상(李箱, 1910–1937)의 모든 텍스트를 기반으로 한 아카이브 웹사이트 워크샵 프로젝트.
「건축무한육면각체」의 '四角の中の四角(사각형 안의 사각형)'에서 출발해, 글자(음절) 하나를 원고지 한 칸 = 큐브 하나로 세우고 모든 글자에 주소를 부여한다.

## 구성

| 경로 | 내용 |
|---|---|
| `archive/` | 作品目錄 — 나무위키 작품 목록 기준 189편. 제목·내용(연도·발표지·비고)과 원문 링크(위키문헌·공유마당·나무위키), 원문 입력 칸 |

## 주소 체계

`층(연도) - 동(종류) - 호(순번) / 면 / 행-열`  예) `1934-詩-01 / 正 / 01-05`

- 동 9개: 詩 小 隨 書 畫 記 寫 評 證
- 방(작품) 6면: 正 원문 · 背 현대어 · 左 지면 · 右 기록 · 天井 연보 · 床 연결
- 상태: 現在 · 施工 · 未施工 · 空

## 데이터 수집 현황 (2026-10-25)

- 전체 목록 189개 항목 중 **129개 항목 본문 수록**. 연작 전체와 개별 편이 함께 포함된 목록상의 항목 수이며, 중복을 제거한 작품 수를 뜻하지 않는다.
- 위키문헌의 확인된 본문을 `archive/data/texts.json`에 저장하고 상세 페이지 전문 칸에 자동 표시한다. 출처 URL·자료 유형·수집일·기여자 표시를 함께 보존했다.
- 「오감도」 15편, 「역단」, 「위독」과 번역 연작은 개별 편의 경계에 따라 나눴다. 1935년/1936년 「지비」는 서로 다른 문서로 연결했다.
- 일문 작품에 연결된 한국어 번역/전사본은 일본어 원문으로 표시하지 않는다. 위키문헌의 번역문 및 전사 표기를 유지했으며 새로 번역하거나 현대어로 고치지 않았다. 일문 전집 전사본 중 역자가 기재되지 않은 경우에는 위키문헌 기여자로 출처를 표시했다.
- 도형이 이미지인 「오감도」 제5호는 원문 도형도 함께 표시한다. 텍스트 입력 칸과 JSON만으로는 원지면의 좌우 반전·들여쓰기·글꼴·도형 배치를 재현하지 않는다. 정확한 지면은 출처를 참조한다.
- **미수록 60개 항목:** 공유마당 PDF 전사가 필요한 두 연작 및 개별 편 16개, 위키문헌에 제목만 있고 본문이 없는 항목 5개, 확인된 본문 출처가 없는 항목 39개. 상세 사유는 `archive/data/collection-report.json`에 기록했다. 미수록 칸에는 미수록 사유를 표시한다.
- 기존 브라우저 입력 내용은 수집 본문보다 우선한다. 개인 수정/삭제는 브라우저에만 저장하며, ‘수집한 본문으로 되돌리기’로 저장소 본문을 복원할 수 있다. 전체 JSON 내보내기에는 수집 본문과 개인 수정본을 함께 포함한다.

### 확인 방법

저장소 루트에서 `python -m http.server 8000` 실행 후 `/archive/`를 연다. 전문 JSON을 가져오므로 `file://`로 직접 열지 않는다.

## 시각 규칙

흰색 `#FFFFFF`, 청색 두 가지만. 형태는 큐브만. 명암 대신 빗금 간격으로 면을 구분. 움직임은 12fps 스냅.
