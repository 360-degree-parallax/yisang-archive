# 李箱 아카이브

작가 이상(李箱, 1910–1937)의 모든 텍스트를 기반으로 한 아카이브 웹사이트 워크샵 프로젝트.
「건축무한육면각체」의 '四角の中の四角(사각형 안의 사각형)'에서 출발해, 글자(음절) 하나를 원고지 한 칸 = 큐브 하나로 세우고 모든 글자에 주소를 부여한다.

## 구성

| 경로 | 내용 |
|---|---|
| `archive/` | 作品目錄 — 나무위키 작품 목록 기준 189편. 제목·내용(연도·발표지·비고)과 원문 링크(위키문헌·공유마당·나무위키), 원문 입력 칸 |
| `cube/` | 原稿紙 큐브 3D 프로토타입 (Three.js r128). 1:1 字 → 1:10 面 → 1:100 室 → 1:1000 層 → 1:10000 建物 |

## 주소 체계

`층(연도) - 동(종류) - 호(순번) / 면 / 행-열`  예) `1934-詩-01 / 正 / 01-05`

- 동 9개: 詩 小 隨 書 畫 記 寫 評 證
- 방(작품) 6면: 正 원문 · 背 현대어 · 左 지면 · 右 기록 · 天井 연보 · 床 연결
- 상태: 現在 · 施工 · 未施工 · 空

## 데이터 수집 현황 (2026-10-25)

- 원문 링크 있음 140편 (연작 개별 편 48편은 부모 작품 문서로 연결)
- 나무위키 문서만 2편
- 링크 없음 47편 — 권두언, 사신, 발굴 일문 작품 등. 전집·국립중앙도서관 자료에서 수집 필요
- 위키문헌 링크 중 15편만 정확한 문서 주소 확인, 나머지는 제목 바로가기(없으면 검색 결과)
- 원문 본문은 저장소에 포함하지 않음. `archive/`의 입력 칸으로 수집 후 JSON으로 내보내 데이터 파일로 옮긴다.
- `cube/`의 원고지는 자리표시(□) 상태. `LINES` 배열에 원문을 넣으면 큐브로 세워진다.

## 시각 규칙

흰색 `#FFFFFF`, 청색 두 가지만. 형태는 큐브만. 명암 대신 빗금 간격으로 면을 구분. 움직임은 12fps 스냅.
